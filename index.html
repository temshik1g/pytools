Как пользоваться

Пошаговые инструкции

🐍 PyUnlocker — восстановление Windows

1

Скачайте и распакуйте

Скачайте PyUnlocker-v3.0.zip, распакуйте в любую папку. Запустите Pyunlocker_new.exe от имени администратора.

2

Восстановление системы

Раздел "Восстановление" → нажмите нужную кнопку: SFC для проверки файлов, DISM для восстановления образа, CHKDSK для проверки диска.

3

Сброс пароля Windows

Раздел "Взлом Windows" → кнопка "Заменить sethc.exe на CMD". Перезагрузитесь, нажмите 5 раз Shift на экране входа. В открывшемся CMD введите: net user Имя НовыйПароль

4

Восстановление загрузчика

Если Windows не загружается → раздел "Восстановление" → "Восстановить UEFI загрузчик" (для UEFI) или "Восстановить Legacy MBR" (для BIOS).

💾 FlashU — создание флешек

1

Скачайте и запустите

Скачайте FlashU-v1.1.zip, распакуйте, запустите FlashU.exe от имени администратора.

2

Выберите ISO образ

Шаг 1 → кнопка "📂 Обзор" → выберите ISO файл Windows или Linux. Программа автоматически определит версию ОС.

3

Вставьте флешку

Шаг 2 → нажмите "🔄" → выберите вашу флешку из списка. ⚠️ Все данные на флешке будут удалены!

4

Настройте параметры

Шаг 3 → выберите режим загрузки и файловую систему. Шаг 4 → можно включить разделение на BOOT + DATA для хранения личных файлов.

5

Создайте флешку

Нажмите "💾 СОЗДАТЬ ЗАГРУЗОЧНУЮ ФЛЕШКУ" → дождитесь завершения (5-20 минут). Следите за журналом справа.

О проекте

Немного о PyTools Suite

PyTools Suite — это набор бесплатных утилит для Windows, написанных на C# + WinUI 3 с использованием современного дизайна Liquid Glass в стиле Windows 11.

Приложения работают полностью автономно — не требуют Python, .NET Runtime или установки Visual Studio. Просто скачайте, распакуйте и запустите.
